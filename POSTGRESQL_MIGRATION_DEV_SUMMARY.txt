       • Window Lookups: Time-bounded SQL range queries on opg_normalized_telemetry.
       • Aggregations: Native SQL date_trunc('hour', timestamp) with avg()/min()/max().
       • Coverage: Min/max timestamp analysis from opg_normalized_telemetry.
