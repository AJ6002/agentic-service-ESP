FIX 1 — VERIFY EV-TRACE-* VS EV-R-* ID FORMAT
================================================================================
Findings:
1. Evidence ID generation occurs in `agent_service/app/evidence/qod.py`:
   `f"EV-{run_id}-{seq:04d}"`
2. In production (`agent_service/app/main.py`), every execution sets:
   `run_id = f"R-{uuid4().hex[:8]}"`
   This generates IDs strictly following the standard production format: `EV-R-<hex8>-<seq4>`.
3. The `EV-TRACE-*` prefix was introduced exclusively inside the diagnostic script
   `scratch/diagnose_op01_op04.py` using `run_id = f"TRACE-{obj_id[:4]}"`.
4. The numeric provenance checker regex in `agent_service/app/synthesis/numeric_check.py` matches:
   `r"EV-[\w\-]+"`
   This pattern already accepts any valid evidence ID prefix (`EV-R-*`, `EV-TRACE-*`, `EV-*`).
5. Conclusion: No code defect exists in production ID generation. Test scripts should adhere to standard production run prefixes (`R-*`).

FIX 3 — EXTEND PROVENANCE CHECK TO COVER KB SECTION REFERENCES
================================================================================
Implementation Details:
1. `agent_service/app/synthesis/citation_check.py`:
   - Updated `extract_pack_citations(pack)` to extract both canonical document IDs AND indexed section tokens from:
     * KB search hits (`item.payload["hits"]`)
     * Causal graph SOP entries (`item.payload["paths"]`)
     * Fault taxonomy documents (`item.payload["faults"]`)
     * Direct formatted hits (`item.payload["doc_id"]`, `item.payload["section"]`)
   - Updated `check_citation_provenance(advisory, pack)`:
     * Parses citation bracket expressions: `r"\[\s*([A-Za-z0-9_\-\.\+]+)(?:\s*\([A-Za-z0-9_\s]+\))?(?:[\s,]+(?:§|Section\s*|sec\.?\s*)([A-Za-z0-9_\.\-]+))?\s*\]"`
     * Checks if `doc_id` is present in pack.
     * If `section` is cited, verifies that `section` is in `pack_sections[doc_id]`.
     * If section is missing from the pack, marks step as unverified: `"[doc §sec] (section not in pack)"`.
     * Added token ignore-list for operational labels (`UNVERIFIED`, `WARNING`, `NOTE`, `LEVELA`, `LEVELB`, etc.).
2. `agent_service/app/workflow/runner.py`:
   - `_format_advisory_text()` receives `citation_res` and surfaces `[WARNING: Citation Provenance Unverified for: ...]` if any unverified citation exists.
   - Enforced zero-fabrication: unverified steps (`citation_res.flagged_steps`) are stripped from `advisory.troubleshooting_steps` before final assembly and return, ensuring fake citations are never displayed to the user.
